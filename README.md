# 🌃 Lofi Cyberpunk Lounge

An immersive, cyberpunk-themed ambient web environment designed for deep work, studying, and coding sessions. Set the perfect vibe with built-in lofi music, a functional focus timer, and customizable visual themes.

## ✨ Features

*   **🎧 Ambient Music:** Built-in audio player featuring relaxing lofi and cyberpunk-inspired tracks to keep you in the zone.
*   **⏱️ Focus Timer:** Integrated countdown timer (perfect for Pomodoro sessions) to help manage productivity and breaks.
*   **🎨 Dynamic Themes:** Toggle between multiple cyberpunk aesthetic themes to match your current mood.
*   **⚡ Lightweight & Fast:** Built for smooth performance without unnecessary bloat.

## 🚀 Getting Started

### Prerequisites
You only need a modern web browser to run this site.
